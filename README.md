# 미용·다이어트 네이버 블로그 글쓰기 도우미

네이버 블로그 상위 노출 블로거 5인의 글 14편을 분석해 만든 "황금 템플릿" 기반 글쓰기 도구입니다.

소재 · 키워드 · 글 유형 · 톤 · 분량 · 경험 메모를 입력하면 템플릿이 반영된 글쓰기 프롬프트가 생성됩니다.
**Claude에서 바로 열기** 버튼으로 프롬프트가 채워진 채 [claude.ai](https://claude.ai)를 열거나, 복사해서 다른 AI에 붙여넣어 초안을 받을 수 있습니다.

## 사용하기

👉 https://kimyoungil21.github.io/naver-blog-writer/

## 템플릿 근거

2026년 8월 기준 다이어트·스킨케어 키워드 상위 노출 네이버 블로거 5인의 실제 글을 분석해 공통 패턴(제목 공식, 서론 후킹, 소제목 구조, 키워드 반복 밀도, 톤앤매너, 마무리 방식)을 추출했습니다. 자세한 내용은 페이지 하단 "분석 근거" 섹션에 있습니다.
